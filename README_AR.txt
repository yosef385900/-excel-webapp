موقع جدول Excel محمي بكلمة سر

كلمة السر المؤقتة الافتراضية: 123456

مهم جداً قبل النشر:
1) عيّن متغير البيئة SITE_PASSWORD إلى كلمة سر جديدة.
2) عيّن SECRET_KEY إلى نص عشوائي طويل.
3) شغّل الموقع بخادم يدعم Python/Flask وقرصاً دائماً (Persistent Disk)، لأن التعديلات تُحفظ داخل data.xlsx.

تشغيل محلي:
pip install -r requirements.txt
SITE_PASSWORD=ضع_كلمة_السر_هنا python app.py
ثم افتح http://localhost:5000

الملفات:
data.xlsx = ملف Excel الأصلي وتُحفظ فيه التعديلات.
app.py = الخادم والحماية بكلمة السر.
templates و static = واجهة الموقع.

ملاحظة: لا تعتمد على كلمة السر الافتراضية عند نشر الموقع على الإنترنت.
